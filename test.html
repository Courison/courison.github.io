⚠️ 重要风险提示
  • 请勿泄露您的 cred 和 token。这两个字段相当于森空岛账号的登录凭证，一旦泄露可能被他人访问您的账号。
  • 本网页仅使用一次。您提供的凭证仅用于一次性获取干员数据，不会保存到任何服务器，不会上传、不会缓存。
  • 请确认您信任本工具。如您对安全性有任何疑虑，请立即关闭此页面。

继续操作前，请确认您已阅读并理解上述风险提示。

步骤 1：打开森空岛官网并登录

点击下方按钮跳转到森空岛官网，使用您的账号完成登录，并保持登录状态（不要退出登录）。

🔗 点击打开森空岛官网

💡 建议 PC 端进行操作，手机端浏览器可能无法调出 F12 控制台。

步骤 2：从浏览器控制台复制凭证

  1. 在森空岛官网页面按 F12 打开开发者工具，切换到 Console（控制台） 标签；
  2. 点击下方 📋 复制代码 按钮，把代码粘贴到控制台后按 回车；
  3. 控制台会输出 undefined（这是正常的），凭证内容已自动复制到剪贴板。
（示意图 /cred.png 加载失败，请确认文件与 index.html 同目录）
copy(localStorage.getItem('SK_OAUTH_CRED_KEY')+','+localStorage.getItem('SK_TOKEN_CACHE_KEY'))

步骤 3：粘贴凭证并获取数据

将上一步复制到剪贴板的内容（格式为 cred,token）粘贴到下方输入框，然后点击右下角 一键获取。

✅ 数据获取成功，请确认导入

⚠️ 重要风险提示
  • 请勿泄露您的 Token。该 Token 相当于鹰角网络账号的临时登录凭证，一旦泄露可能被他人访问您的账号。
  • 本网页仅使用一次。您提供的 Token 仅用于一次性获取干员数据，不会保存到任何服务器，不会上传、不会缓存。
  • 请确认您信任本工具。如您对安全性有任何疑虑，请立即关闭此页面。

继续操作前，请确认您已阅读并理解上述风险提示。

步骤 1：打开鹰角网络通行证并登录

点击下方按钮跳转到鹰角网络通行证，使用您的账号完成登录，并保持登录状态（不要退出登录）。

🔗 点击打开鹰角通行证

💡 移动端和 PC 端均可操作，无需打开浏览器控制台。

步骤 2：获取 Token

  1. 保持上一步的登录状态（同一个浏览器，不要退出登录）；
  2. 点击下方按钮打开 Token 页面；
  3. 页面会显示一段 JSON 文本，把整段内容复制下来（工具会自动识别其中的 Token）。
🔗 点击获取 Token

💡 手机端看到一段 JSON 文本是正常的，全选复制即可。

步骤 3：粘贴 Token 并获取数据

将上一步复制的内容（整段 JSON 或仅 content 值均可）粘贴到下方输入框，然后点击右下角 一键获取。

✅ 数据获取成功，请确认导入
