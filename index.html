⚠️ 使用前请了解
  • 涉及范围：游戏数据。您粘贴的 cred 是森空岛侧读取游戏数据的凭据，token 用于对请求签名。泄露后他人可读取您的终末地角色信息（干员、基建、精英化等）。
  • 不含登录能力。该凭据无法登录您的森空岛账号、无法进行发帖、充值等账号级操作，风险限于数据读取。
  • 一次性使用。本页面通过前端直接向森空岛接口发起请求，凭证不上传到本工具服务器，也不写入本地存储。
  • 用完请自行更换。操作完成后，在森空岛官网退出登录即可使该凭据失效。

继续操作前，请确认您已阅读并理解上述说明。

步骤 1：打开森空岛官网并登录

点击下方按钮跳转到森空岛官网，使用您的账号完成登录，并保持登录状态（不要退出登录）。

🔗 点击打开森空岛官网

💡 建议 PC 端进行操作，手机端浏览器可能无法调出 F12 控制台。

步骤 2：从浏览器控制台复制凭证

  1. 在森空岛官网页面按 F12 打开开发者工具，切换到 Console（控制台） 标签；
  2. 点击下方 📋 复制代码 按钮，把代码粘贴到控制台后按 回车；
  3. 控制台会输出 undefined（这是正常的），凭证内容已自动复制到剪贴板。
💡 首次使用控制台无法粘贴？
  • Chrome、Edge 等浏览器出于安全考虑，第一次在控制台粘贴代码时会拦截并弹出一段提示。
  • 此时请手动在控制台输入 "allow pasting"/"允许粘贴" 并按回车，之后就可以正常粘贴了。
  • 这只是一次性的浏览器安全确认，不会执行任何代码，输入后重启浏览器也无需再次输入。
（示意图 /cred.png 加载失败，请确认文件与 index.html 同目录）
copy(localStorage.getItem('SK_OAUTH_CRED_KEY')+','+localStorage.getItem('SK_TOKEN_CACHE_KEY'))

步骤 3：粘贴凭证并获取数据

将上一步复制到剪贴板的内容（格式为 cred,token）粘贴到下方输入框，然后点击右下角 一键获取。

步骤 4：确认账号

已识别到以下终末地账号，请确认是您要导入的账号。确认无误后点击右下角 查看天赋。

⚠️ 使用前请了解
  • 涉及范围：鹰角账号。您粘贴的 Token 是鹰角网络通行证下发的临时登录凭证，可用于访问该账号的账号信息与游戏绑定数据，是三种方式中权限最高的一种。
  • 会经过本工具服务器。后端 /api/hg-to-cred 用该 Token 换取森空岛凭据，再拉取干员数据。服务器仅在内存中转发，不落盘、不记录日志。
  • Token 有效期较短。一般为几十分钟至数小时，过期自动失效，之后无法再使用。
  • 建议操作后修改密码。若您对账号安全较为敏感，可在导入完成后修改一次鹰角通行证密码，旧 Token 立即失效。

继续操作前，请确认您已阅读并理解上述说明。

步骤 1：打开鹰角网络通行证并登录

点击下方按钮跳转到鹰角网络通行证，使用您的账号完成登录，并保持登录状态（不要退出登录）。

🔗 点击打开鹰角通行证

💡 移动端和 PC 端均可操作，无需打开浏览器控制台。

步骤 2：获取 Token

  1. 保持上一步的登录状态（同一个浏览器，不要退出登录）；
  2. 点击下方按钮打开 Token 页面；
  3. 页面会显示一段 JSON 文本，把整段内容复制下来（工具会自动识别其中的 Token）。
🔗 点击获取 Token

💡 手机端看到一段 JSON 文本是正常的，全选复制即可。

步骤 3：粘贴 Token 并获取数据

将上一步复制的内容（整段 JSON 或仅 content 值均可）粘贴到下方输入框，然后点击右下角 一键获取。

步骤 4：确认账号
